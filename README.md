# Tessa 🤖

> A personal AI assistant that doesn't just chat. It plans, uses tools, remembers context, and gets things done.

Tessa is an AI assistant platform designed to turn natural-language requests into executable tasks.

Instead of simply generating a response, Tessa can understand a task, break it down, select the appropriate tools, execute them, maintain context, and continue working until the task is completed.

---

## ✨ What is Tessa?

Tessa is built around the idea of an **agentic AI assistant**.

You give Tessa a goal:

```text
"Remind me to check the server tomorrow morning."

"Find all unread emails from the last week and summarize them."

"Create a report from this dataset."

"Monitor this service and tell me if it goes down."

"Search for companies matching these requirements and add them to my leads."
